## Summary

The objections I would most want the lead to act on, in order:

1. **S-anthropics-sandbox-runtime-1 (blocker).** srt's credential masking substitutes the real key into request bodies to every inject host (`http-proxy.ts:812-818`, `body-substitution.ts:59-80`) and relays responses unchanged (`tls-terminate-proxy.ts:1409-1471`); an LLM provider echoes, so a child gets the key back. "Child never sees the key" is not demonstrated; the R03 half of the top-ranked os_kernel candidate needs an echo test and a header-only mode before any R03 claim. Split its score row (W-1).
2. **X-1 / TM-1 (security state in the child-writable root).** Ten dossiers place revocation sets, keys, watermarks, ledgers, job DBs, git dirs or permission files where delegated children and add-ons can write. Define one bridge-only, integrity-protected state location (with R15) and require every first PR to use it; add threat T21.
3. **X-4 / TM-2 (self-approval and misdisplay).** Every approval design ends in a route or prompt the agent's own extension context can reach or render. Specify an approval path the agent cannot drive, an out-of-band credential enrolment, and the fault case "agent asks for A while showing B"; add threat T22.
4. **X-5 (broker versus containment on loopback).** Decide the R03 broker transport jointly with R02 and R05 before PRs start: separate low-privilege broker process on a Unix socket or inherited pipe, never the bridge's main listener (S-getaegis-aegis-1, S-anthropics-sandbox-runtime-2).
5. **X-10 / W-4 (anchor consistency).** Clarify the isolation anchor (artifact-level 0; tests must exercise the property), then re-score openworkflow and dapr under one T7 rule, nanobrowser, solana-foundation-rewards and the split srt row, and add a score-perturbation pass to `sensitivity.py` (W-6).
