Regional platforms: use their JSON APIs, not their HTML; several HTML fronts are bot-walled and GitLab-family search matches only name and description, not README text.

Why: the Stage 2 term-bank agents (2026-10-20) found hal.science HTML pages, FranceTerme, Korben and git.rwth-aachen.de blocked by bot checks, while the HAL API (api.archives-ouvertes.fr), Framagit API, openCode.de API (gitlab.opencode.de/api/v4) and most university GitLab APIs answer anonymously. code.gouv.fr has no server-side query; its data file (code.gouv.fr/data/repositories.json, 17,851 repos) stops in 2024. Helmholtz RSD content is English, so native-language queries return nothing there. GitHub search rate-limits after roughly 30 queries per agent.

How to apply: query GitLab-family hosts with one short keyword per call (/api/v4/projects?search=WORD); search English terms on regional platforms where the glossary says practitioners keep the English word; download the code.gouv.fr JSON once and filter locally with python -I rather than probing the site; treat Helmholtz RSD as an English index. Chinese platforms (s2-term-zh, 2026-10-20): Gitee search is closed anonymously (web search redirects to so.gitee.com and returns empty; /api/v5/search/repositories returns [] without a token), but /api/v5/repos/OWNER/REPO lookup by name works, so discover on GitHub or GitCode with Chinese terms and then resolve the Gitee upstream by name. OpenI: openi.pcl.ac.cn is the Gitea-based forge but its search pages sit behind an agreement gate; openi.org.cn behaves like a portal (unverified). CNKI search loads but returns nothing anonymously.
