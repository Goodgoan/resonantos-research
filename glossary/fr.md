# French term bank (fr) for Stage 2 discovery

- Language: French (fr). Agent: s2-term-fr. Date: 2026-10-20.
- Scope: 16 core concepts (Table 1) and requirements R01-R30 (Table 2) from stage1/gaps.md.
- Evidence labels: **inspected** = I opened the page or queried the API and read the record; **reported** = seen only in a search snippet or result title. All dates below are the day I saw the item (2026-10-20) unless a publication date is given.

## Method summary

1. Queried HAL (API, quoted phrases, `language_s:fr`) for about 90 French candidate terms and read title, keywords and French abstracts of the useful hits.
2. Queried the Framagit GitLab API (`/api/v4/projects?search=`), downloaded the code.gouv.fr repository inventory (17,851 repositories) and grepped names and descriptions with regexes.
3. Queried GitHub with `gh api -X GET search/repositories` for French phrases. The search quota (30/min) ran out once; later queries waited and succeeded. No code search was used.
4. WebSearch (standard, a few extended) for practitioner articles, blogs, LinuxFr, Korben, vendor FR blogs; WebFetch for the pages that mattered. FranceTerme was checked only through secondary sources (see platform notes).
5. Disconfirmation: for every native term I looked for technical use, not dictionary use. Terms that returned only dictionary, vendor-glossary or false-positive hits are in the Rejected section or marked "official, unused".

## Headline findings

1. French practitioners write the English term untranslated for most of this domain: MCP, workflow, sandbox, local-first, token (in "token d'accès"), proxy, deny-by-default, headless, microVM, Firecracker. Search English on regional platforms for R01, R06, R08, R09, R10, R16, R24.
2. "bac à sable" is the one strongly attested native security term (inspected: Novita FR article, LinuxFr bubblewrap series, LinuxFr 2026-03 proxy article, HAL Firejail talk keyword "Sandbox"). Its confinement synonym "confinement" works only with Linux/process words.
3. "jeton" is the official FranceTerme word for token (reported, BO 2021) and is also used by practitioners. "jeton non transférable" returns nothing; "soulbound" and "jetons liés à l'âme" appear only in news media.
4. "système multi-agents" (SMA) in HAL means classical multi-agent research from the 1990s-2010s, not LLM agent frameworks. LLM-era French uses "agents IA", "agents LLM", "agent conversationnel".
5. "local-first" is never translated by practitioners; "hors ligne d'abord" (offline-first) exists on GitHub but is a different concept; "local d'abord" is not used.

## Platform notes for the French language agent

**HAL API**
- Base: `https://api.archives-ouvertes.fr/search/?q="PHRASE"&fq=language_s:fr&fl=title_s,uri_s,docType_s,producedDate_s,abstract_s,keyword_s&rows=5&wt=json`. Quote phrases; unquoted multi-word queries return noise.
- `numFound` is a rough scale: polysemous terms return thousands. Narrow with `fq=producedDate_s:[2023 TO *]` or add a second phrase.
- Fetch a record by `q=halId_s:hal-XXXXXXXX`. Use this instead of hal.science pages, which WebFetch cannot open (Anubis wall).
- Software deposits: `fq=docType_s:SOFTWARE`. French-language software deposits are only 128 in total, while all software deposits match English queries far more often; search English title/abstract with `docType_s:SOFTWARE` and drop `language_s:fr`. A search of agent/provenance/sandbox terms with SOFTWARE gave 62 hits, including Provena (hal-05632011, "Reproducibility Package for Evidence-Laundering Stress Tests in AI Governance", 2026) and ADI (hal-05531230, a library for AI agents).
- Software Heritage link: each SOFTWARE record carries `swhidId_s`, a SWHID such as `swh:1:dir:...;origin=https://hal.archives-ouvertes.fr/hal-XXXXXXXX;visit=...;anchor=...`. The `origin=` shows whether the archived repository came from HAL itself or from an upstream forge (for example hal-05373436 "Magrit" points to origin github.com/riatelab/magrit). Resolve with `https://archive.softwareheritage.org/api/1/resolve/<swhid>/` (200 verified) or open `https://archive.softwareheritage.org/<swhid>`.

**Framagit** (GitLab instance)
- Search: `https://framagit.org/api/v4/projects?search=TERM&order_by=last_activity_at&per_page=20`; `X-Total` header gives the hit count; no token needed.
- The API searches name and description only, not code or README text, and French phrases with spaces behave as a loose AND. Results skew to education, associations and small tools; zero hits for "capability", "journal d'audit", "workflow durable", "multi-agents".
- Upstream vs mirror: read the JSON fields `mirror`, `import_url`, `forked_from_project` and `description` ("Fork de https://framagit.org/..." appears in descriptions). A Framagit project with `mirror: false` and `import_url: null` (example basthon/basthon-console, inspected) is a primary repo. To check a GitHub mirror, read the README header and look for "mirror"; the GitHub side shows "mirrored from" only in its description. Not tested on a GitHub-side mirror because none surfaced.
- Examples seen: framagit.org/dynamicskillset/nvAge (local-first notes, active 2026-09), ranperry/minim-mcp (MCP, 2026-10-20), jaj/laribdb_mcp, interhop/linkr/linkr-mcp-bench.

**code.gouv.fr**
- The site is a client-side app. The searchable data is https://code.gouv.fr/data/repositories.json (6 MB JSON array, 17,851 repos, Last-Modified 2024-09-18). Keys: `fn` (full name), `n` (name), `d` (description), `p` (platform), `l` (language), `li` (licence), `o` (organization URL), `id` (repo URL), `u` (last update), `a` (age?), `f` (forks), `f?` (is fork), `t?`, `c?`, `p?`.
- Download once and grep locally; there is no server-side query API (/api/v1/ and /data/organizations.json returned 404). `/sources/` redirects to the data.gouv.fr dataset page "Inventaire des codes sources de logiciels publiés par des organismes publics".
- Caveat: the inventory stops in 2024. It has no MCP, local-first or agent-security repositories, so French public-sector hits for 2025-2026 topics must come from GitHub orgs directly (for example etalab-ia in the inventory: Albert conversational agent, 2024).
- Platforms: github.com 5,911, gitlab.univ-nantes.fr 1,823, gitlab.univ-lille.fr 1,506, gitlab.in2p3.fr 845, forgemia.inra.fr 709. University forges mean many hits are teaching projects.

**GitHub**
- `gh api -X GET search/repositories -f q='"phrase"'` (note `-X GET`: with `-f` alone gh defaults to POST and returns 404). Quoted French phrases return few results, often 0-10 repos, many with 0 stars. Search limit is 30 per minute; I hit a 403 after about 11 quick queries and recovered after about 20 seconds.
- Useful French-tagged hits: "serveur MCP" (10 repos), "orchestrateur d'agents" (8), "hors ligne d'abord" (4), "bac à sable" agent IA (essaim-agents).

**LinuxFr / blogs / news**
- LinuxFr news and journaux are good term sources (bac à sable, sandboxer). Direct `curl` returns 403; WebFetch worked on /news pages but 403 on a journal link; use WebSearch with `allowed_domains: ["linuxfr.org"]`.
- Korben, Siècle Digital, Journal du Net, Journal du Coin cover lay vocabulary. Vendor FR pages (Novita, Didit, Corbado, Tech Insider, Textcortex) are translated or machine-written; count only as usage evidence of the vocabulary, flagged "vendor".

**FranceTerme**
- Direct access failed (see platforms table). Use secondary sources: the Bulletin officiel and Journal officiel. Official terms apply to State administrations; practitioners often ignore them.
